# Contributing to Expense Management

First off, thank you for considering contributing to the Expense Management system! It's people like you that make the open-source community such a fantastic place to learn, inspire, and create.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](../../issues) first. If it's not there, feel free to open a new issue.

## Setting up for Local Development

1. Fork the repo and create your branch from `main`.
2. Clone your fork locally.
3. CD into `backend` and run `npm install`.
4. CD into `frontend` and run `npm install`.
5. Create `.env` files in both directories based on the provided `.env.example`.
6. Use `npm run dev` in the frontend and `npm start` in the backend.

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, this includes new environment variables, exposed ports, useful file locations and container parameters.
3. You may merge the Pull Request in once you have the sign-off of two other developers, or if you do not have permission to do that, you may request the second reviewer to merge it for you.

## Code Style

- We use ESLint and Prettier for JavaScript code formatting.
- Ensure your code passes all lint checks before committing.
- Commit messages should be clear and concise.

Thank you for your contributions!
